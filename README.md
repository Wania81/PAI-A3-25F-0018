# PAI Assignment 3

How to run: 
Install Python 3 with numpy, pandas, matplotlib and Jupyter. Keep the folder structure as it is (data/ next to the notebook), open `Assignment3_Programming_for_AI.ipynb` and use Kernel > Restart and Run All. The notebook creates `outputs/dashboard.png`, `outputs/dashboard.pdf` and `outputs/wave.gif`.

One hard thing:the Q6 dashboard was the hardest part, because placing six panels in one figure without overlapping legends, labels and the inset took many attempts. Q7 was also tricky, especially the 3D surface and the wave animation.
